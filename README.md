# Repository Notice: Takedown and Discontinuation

This repository has been taken down and is no longer maintained.

We recently received a formal legal notice (Cease and Desist) from legal counsel representing **Xfar Records**, demanding the removal of all code, assets, and materials related to the bypass and reverse engineering of **Sarum Faded**.

To comply with the request and respect applicable intellectual property rights:

* All relevant code, binaries, and documentation have been permanently removed.
* Development, distribution, and support for this project have ceased immediately.
* No forks, mirrors, or alternative distribution channels are authorized or maintained by this project.

We appreciate the community's past interest and understanding regarding this compliance action.
